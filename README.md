# 🎂 Age Calculator

A simple and interactive Age Calculator built using **HTML, CSS, and JavaScript**.

This project allows users to calculate their age by entering their date of birth. It calculates the exact age in years, months, and days.


## 🛠️ Technologies Used

- **HTML5** – Structure of the application.
- **CSS3** – Styling and layout.
- **JavaScript** – Age calculation logic and interactivity.



## 🎯 Project Purpose

This project was created as part of my journey in learning JavaScript and Front-End Development.

It helped me practice:
- JavaScript Date objects.
- Variables and calculations.
- Functions and conditions.
- DOM manipulation.
- User interaction.
